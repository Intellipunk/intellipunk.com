# AGENTS.md — Intellipunk Execution Contract

## Purpose
You are helping maintain and expand the Intellipunk project (writing + structure + publishing assets).
Optimize for clarity, falsifiability, and consistency with existing canon.

## Non-goals
- Do not turn Intellipunk into generic solarpunk/hopepunk copy.
- Do not add utopian claims without mechanisms.
- Do not moralize. No inspirational tone.

## Canon sources (highest priority)
- docs/manifesto.md
- docs/theses.md
- docs/glossary.md
- adr/*

If canon conflicts with your suggestion, highlight the conflict and propose a patch.

## Definitions (must stay consistent)
- Intellipunk: decentralized intelligence + energy realism + anti-AI empires.
- Antagonists: centralized compute monopolies, closed models, extractive clouds, grid capture.
(Add more in docs/glossary.md.)

## Voice and style
- Short sentences. Concrete nouns/verbs.
- Prefer mechanisms over adjectives.
- Avoid vague phrases: “reimagine”, “empower”, “a better future”.

## Work protocol
- Make the smallest coherent change set.
- For writing tasks: propose an outline first if ambiguity is high; otherwise draft directly.
- For repo edits: preserve structure; don’t rename files casually.

## Output formats
- Manifesto sections: `docs/manifesto.md` headings + 3–7 bullet theses each.
- FAQ: question + 2–5 sentence answer.
- Press kit: 1-paragraph description + 5 bullets + 3 taglines.

## Evidence rules
- If making factual claims about real-world entities, include citations/links.
- If speculative, label it as a working theory.

## Quality checks before final
- Does each key claim imply a mechanism?
- Any term used differently than glossary?
- Any drift toward generic “punk aesthetic” without substance?
